# Exchange — Currency Converter

**Live demo: [exchange.hashimsalim.com](https://exchange.hashimsalim.com/)**

Convert between 160+ currencies, see what you'd have gained or lost by converting on a past date, and explore exchange-rate history with major events marked.

Static site (HTML/CSS/JS, no build step). Rates from the [Frankfurter API](https://frankfurter.dev).

Run locally: `python3 -m http.server 5391`
